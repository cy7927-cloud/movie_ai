激活现成专业Skill的哪些能力

这是原版Skill的外部任务配置，不是改写它们的源码；还没有取得上游Agent的独立执行回执。

scene_space

调用现成Skill：ai-storyboard-director

激活：spatial-reveal / shot-design-engine / framing-and-axis

同一片段内水边、门廊、巨大建筑、室内及街市多层空间互相转换

边界：不能机械规定所有镜头都要对称或大景

object_insert

调用现成Skill：director-agent + ai-storyboard-director

激活：visual-storytelling / object-motif / audience-information-order

黑猫、书卷、地面痕迹、器物被给予单独观看时间

边界：不能将任何插入镜头自动认定为角色主观所见

architecture

调用现成Skill：ai-storyboard-director + plan-camera-shots

激活：framing-and-axis / architectural-depth / spatial-baselines

桥、廊柱、格窗、建筑中轴反复成为人物行动框架

边界：不能凭缩略图反推出真实焦距

blocking

调用现成Skill：plan-camera-shots

激活：character-start-end-state / blocking-continuity / camera-position-and-focus

长廊、夜间广场、街市及桥道均有较明显的演员移动

边界：不能只用固定静帧证明摄影机轨迹

performance_timing

调用现成Skill：director-agent + ai-storyboard-director

激活：performance-beats / micro-actions / performance-time-budget

近身互动、静对、转头、靠近、离开有不同速度的动作段落

边界：表情与情绪需连贯视频和对白复核

occlusion

调用现成Skill：ai-storyboard-director + plan-camera-shots

激活：foreground-masking / visual-discovery / screen-direction-check

薄帘、柱廊、门窗、格栅反复挡住或局部显露人物

边界：不能一概定义遮挡为悬念或偷看

lighting_context

调用现成Skill：ai-storyboard-director

激活：color-and-image-formation / scene-motivated-light / warm-cool-scene-contrast

日光金色、暗暖烛光、青蓝色地下空间在片段内并存

边界：严禁整片套用同一个暗金色滤镜
