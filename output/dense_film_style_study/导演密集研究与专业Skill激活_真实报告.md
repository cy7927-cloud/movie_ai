## 全时间轴：真实观察与待证解释

### 00:00–01:00　水边开阔空间、人物与黑猫、室内纵深
**可复查画面事实：** 浅金色水边远景里有人物站在近水处；随后出现人物侧身回望与黑猫近景；约00:36后转换为门廊和圆形亮窗的室内画面。
**待证导演解释：** 室外开阔画面到室内门窗空间的交替提供了两种不同的观看距离；猫成为显眼的视觉信息点。
**不得擅自确定：** 不要断言猫是人物的主观视线所见；不可由画面判定人物真实动机。
**激活能力：** scene_space, object_insert, architecture；参考时间码：10s, 21s, 39s, 52s

### 01:00–02:00　猫的移动、庭院步行、地面细节
**可复查画面事实：** 黑猫在门窗内外活动；浅色服饰人物从室内转至岩石和庭院空间；约01:42–01:52画面集中于地面的红褐色痕迹及小型物件。
**待证导演解释：** 移动主体和突然强调的物件细节改变观众要注意的对象。
**不得擅自确定：** 红褐色痕迹的成因和物件性质不能只凭缩略图确认。

## 15组重点动作/构图研究

- **00:15.00–00:30.00｜人物回望与猫的显露**：开阔水边与近身画面的注意对象切换。调用 `director-agent` 的 camera/eyeline uncertainty；未证：确认是否为视线匹配需要较完整方向镜头
- **01:15.00–01:30.00｜室内移动的黑猫与人物**：黑猫在日光投影明显的室内经过，之后画面回到人物。调用 `ai-storyboard-director` 的 audience information vs POV；未证：剪辑主观性未确认
- **02:15.00–02:30.00｜红衣人物经过廊柱**：重复立柱构成横向深度，走位延续到推门区域。调用 `plan-camera-shots` 的 spatial baseline / actor path；未证：无法判断机位是否真正移动
- **03:15.00–03:30.00｜灯烛与书卷**：文书和灯火的近景被人物画面包围。调用 `director-agent` 的 object motivated attention；未证：书卷意义需对白/上下文
- **04:15.00–04:30.00｜猫的云雾段与人物转头**：4:17开始黑猫意象，4:19切回浅色衣人物的头部转向。调用 `ai-storyboard-director` 的 non-POV insert / knowledge gap；未证：不得推断人物看到猫
- **05:15.00–05:30.00｜廊柱前的移动**：人物通过楼阁栏边，竖向立柱多次遮挡。调用 `plan-camera-shots` 的 foreground occlusion；未证：判断跟拍/静机位需连贯视频
- **06:30.00–06:45.00｜夜间双人同框与背向关系**：人物在广场上出现面向及背向关系，镜头切入双人脸部。调用 `director-agent` 的 performance and orientation；未证：无台词、人物动机待核验
- **07:15.00–07:30.00｜绿色薄帘内的双人动作**：两人从俯身位置逐渐移动到正面近距离，浅绿帘持续作为前景。调用 `ai-storyboard-director` 的 blocking beats / screen direction；未证：不能确认台词与情感指向
- **08:45.00–09:00.00｜青绿色台阶与金色装置**：青蓝色阶梯转向明显发光的金色器物，冷暖对照强烈。调用 `ai-storyboard-director` 的 color and image formation；未证：不把色差自动解释为场景好坏
- **09:15.00–09:30.00｜金色纹样墙与器物**：深色人物与饰纹物件的过肩关系和独立器物细节。调用 `director-agent` 的 object motif + audience attention；未证：物件用途与象征未知
- **10:00.00–10:15.00｜红衣人物、黑猫、深衣人物**：红衣近景后黑猫在金色栏杆行走，深衣人物单独出镜，间隔空间镜头。调用 `ai-storyboard-director` 的 non-POV insert；未证：人物是否看到猫未确认
- **10:15.00–10:30.00｜门窗与室内空间揭示**：窗格、暗墙、开敞的日光室内依次出现，并有不同人物出镜。调用 `plan-camera-shots` 的 room entry / geography；未证：镜头的时间顺序不等于建筑的实测平面图
- **10:30.00–10:45.00｜对坐的准备和接近**：深衣人物移动至亮窗房间并与浅衣人物靠近，桌案与窗格充当参照。调用 `plan-camera-shots` 的 blocking / over-shoulder；未证：真实走位尺寸未知
- **11:30.00–11:45.00｜街市行进与格窗**：不同角色穿过人群，转为从格窗内观察。调用 `ai-storyboard-director` 的 occlusion / visual reveal；未证：无法推断谁在监视谁
- **12:20.00–12:35.00｜廊桥同行**：两人沿木质走廊继续移动，背景深处可见其他人。调用 `plan-camera-shots` 的 walk-and-talk spatial path；未证：运镜方向需审视频连续帧而非单帧

## 量化检查只作为研究工具

- 每15秒记录60张四帧每秒抽样的平均亮度、饱和度、暗像素比例、跨帧绝对差分和声音RMS。
- 595处高敏感变化和116处强变化**只是检测候选**，不能由数量宣称影片的剪辑点或导演好坏。

- 不使用单一暗金色LUT替代《妖猫传》的多场景风格；日光、烛光、青绿空间有明显差异。
